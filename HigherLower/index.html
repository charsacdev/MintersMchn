Barrier — —

With % of balance ticked, each contract is staked at that percentage of the live account balance, rounded to a whole number and recalculated at every cycle — it grows as the balance grows and shrinks as it falls. The fixed stake boxes are ignored while it is on. Alternate A/B swaps which side carries the extra contracts each cycle; it does nothing when both sides are equal. Trend only holds fire while the zigzag reads as ranging and opens a cycle only on HH/HL or LH/LL — both legs still go on, so it changes when the bot trades, not which way it leans.
